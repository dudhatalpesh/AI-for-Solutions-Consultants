# Module 07 — Security Considerations

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

| Risk | Control |
|---|---|
| Excessive agency | Minimal tools; read-only by default; approvals for writes |
| Tool parameter injection | Validate parameters in the tool; allow-lists |
| Unlogged actions | Log every tool call with execution ID |

See also the [AI security playbook](../../docs/06-ai-security-playbook.md).
