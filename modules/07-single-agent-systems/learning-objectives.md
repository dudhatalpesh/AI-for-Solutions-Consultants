# Module 07 — Learning Objectives

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

By the end of this module you can:

1. Explain the agent loop and tool calling
2. Build an AI Agent with three tools, memory and tool-call logging
3. Put a restricted tool behind human approval
4. Identify agent failure modes and mitigations
5. Write good tool names and descriptions
