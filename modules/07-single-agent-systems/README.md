# Module 07 — Single-Agent Systems

**Phase 6 · Week 7 (standard) · ~6–7 hours · Intermediate**

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

## Why this matters for SCs

Agents are where customer excitement and security anxiety peak. SCs must explain how tool calling works, where it fails, and how to constrain agency with least privilege, approvals and logging.

## Business use cases

- Account research using CRM and status APIs
- IT operations assistant that checks systems and opens tickets
- Security analyst copilot that enriches alerts
