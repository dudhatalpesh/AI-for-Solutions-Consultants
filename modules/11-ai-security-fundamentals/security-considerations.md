# Module 11 — Security Considerations

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

| Risk | Control |
|---|---|
| Prompt injection (LLM01) | Layered guards; least privilege; output validation |
| Sensitive information disclosure (LLM02) | Entitlement-filtered retrieval; redaction; output scanning |
| Improper output handling (LLM05) | Escape and validate output; never execute it |
| Excessive agency (LLM06) | Minimal tools; approvals |

See also the [AI security playbook](../../docs/06-ai-security-playbook.md).
