# Module 11 — Knowledge Check

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

## Questions

1. What's the difference between direct and indirect injection?
2. Why isn't the system prompt a security control?
3. What is residual risk?

## Answers

1. Direct comes from the user; indirect is hidden in content the model reads.
2. It can be overridden or extracted.
3. Risk remaining after controls, which must be accepted by an owner.
