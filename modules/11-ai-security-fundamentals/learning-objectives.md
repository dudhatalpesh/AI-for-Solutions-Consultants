# Module 11 — Learning Objectives

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

By the end of this module you can:

1. Explain the OWASP Top 10 for LLM Applications (2025)
2. Demonstrate direct and indirect prompt injection on an isolated vulnerable workflow
3. Implement input, retrieval and output guardrails in n8n
4. Explain excessive agency, improper output handling, supply chain and shadow AI
5. Write a residual-risk statement
