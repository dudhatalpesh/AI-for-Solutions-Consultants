# Module 11 — AI Security Fundamentals

**Phase 10 · Week 10 (standard) · ~6–7 hours · Intermediate**

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

## Why this matters for SCs

Security teams are now the gatekeepers for AI projects. SCs with a security background can lead here: map OWASP LLM risks to concrete controls, show a vulnerable vs hardened design, and state residual risk honestly.

## Business use cases

- Security review of a customer's RAG assistant
- Shadow AI discovery and governance
- Secure design for agent integrations
