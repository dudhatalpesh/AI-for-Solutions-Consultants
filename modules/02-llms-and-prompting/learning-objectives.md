# Module 02 — Learning Objectives

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

By the end of this module you can:

1. Write prompts with role, task, context, constraints, format and examples
2. Apply zero-shot, few-shot, chain-of-thought-style and step decomposition patterns appropriately
3. Use system prompts and structured output reliably in n8n
4. Compare models and temperatures side by side
5. Explain prompt limits: what needs RAG, tools or fine-tuning instead
