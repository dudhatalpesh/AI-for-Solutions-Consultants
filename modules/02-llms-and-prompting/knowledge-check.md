# Module 02 — Knowledge Check

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

## Questions

1. What six elements make up a well-structured prompt?
2. When is few-shot prompting most useful?
3. Why delimit user input?
4. What does prompting NOT fix?

## Answers

1. Role, task, context, constraints, output format, examples.
2. When the format or judgement is hard to describe but easy to show.
3. To separate data from instructions and reduce injection risk.
4. Missing knowledge (needs RAG), actions (needs tools), and safety on its own (needs controls).
