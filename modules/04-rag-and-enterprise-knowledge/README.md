# Module 04 — RAG and Enterprise Knowledge

**Phase 3 · Week 4 (standard) · ~6–7 hours · Intermediate**

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

## Why this matters for SCs

Retrieval-augmented generation (RAG) is the default architecture for enterprise knowledge assistants. Customers will ask how it handles permissions, freshness, citations and wrong answers — the SC who can answer those wins the architecture discussion.

## Business use cases

- Policy and procedure Q&A
- Product documentation assistant
- Security operations runbook search
- Pre-sales RFP answer drafting
