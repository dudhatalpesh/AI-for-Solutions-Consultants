# Module 04 — Learning Objectives

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

By the end of this module you can:

1. Explain the RAG pipeline: ingest, chunk, embed, store, retrieve, generate
2. Build ingestion and query workflows in n8n with Qdrant
3. Return answers with citations and an insufficient-context fallback
4. Schedule refresh of the knowledge base
5. Evaluate RAG with a small eval set
