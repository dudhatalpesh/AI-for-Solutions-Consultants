# Module 03 — Troubleshooting

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

| Symptom | Fix |
|---|---|
| Agent never calls the FAQ tool | Use a tool-capable model; improve tool description |
| Bot forgets earlier messages | Check session key; increase context window length |
| Chat UI not loading | Workflow must be published for the public chat URL; check Chat Trigger mode |

See also the [global troubleshooting guide](../../docs/08-troubleshooting-guide.md).
