# Module 08 — Multi-Agent Systems

**Phase 7 · Week 8 (standard) · ~6–7 hours · Intermediate–Advanced**

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

## Why this matters for SCs

Customers hear 'multi-agent' everywhere. SCs need to know when splitting work across specialised agents improves quality, and when it only multiplies cost, latency and failure points.

## Business use cases

- Research and report generation
- Proposal / RFP drafting with review
- Incident analysis with planner and reviewer
