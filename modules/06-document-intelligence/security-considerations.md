# Module 06 — Security Considerations

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

| Risk | Control |
|---|---|
| PII in documents | Redact before model; minimise stored fields; retention |
| Malicious documents (injection, malformed files) | Size/type limits; extraction to fixed schema; sandboxed parsing |
| Wrong values auto-posted to finance systems | Validation rules + human approval below threshold |

See also the [AI security playbook](../../docs/06-ai-security-playbook.md).
