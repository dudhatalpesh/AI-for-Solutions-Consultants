# Module 06 — Learning Objectives

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

By the end of this module you can:

1. Explain OCR vs native text extraction
2. Extract fields to a JSON schema with Information Extractor
3. Validate fields and compute a confidence score
4. Route low-confidence documents to human review
5. Redact PII before model calls and storage
