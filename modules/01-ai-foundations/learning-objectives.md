# Module 01 — Learning Objectives

By the end of this module you can:

## Explain (business and technical)

1. Explain the difference between AI, machine learning (ML), generative AI and large language models (LLMs) in two sentences each.
2. Explain what a **token** is and why it drives cost, limits and latency.
3. Explain what an **embedding** is and why it enables semantic search.
4. Explain the **context window** and what happens when you exceed it.
5. Explain **temperature** and when to set it low or high.
6. Explain **hallucination**, why it happens, and three ways to reduce it.
7. Explain the trade-offs between **local and cloud models** (privacy, cost, quality, latency, operations).

## Do (hands-on)

8. Run n8n and Ollama locally with Docker Compose and verify each service.
9. Build an n8n workflow that sends text to a local model and returns validated JSON.
10. Add retry and error handling so failures return a clean error, not a crash.
11. Measure token counts and latency for a prompt, and compute embedding similarity, using Python.

## Advise (consultant)

12. Classify a customer idea as conversational AI, document AI, workflow automation or agentic AI.
13. Ask five discovery questions that reveal whether an AI use case is viable.
14. Respond to the "it just makes things up" objection with a credible answer.

Check yourself with the [knowledge check](knowledge-check.md).
