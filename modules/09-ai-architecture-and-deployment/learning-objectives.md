# Module 09 — Learning Objectives

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

By the end of this module you can:

1. Deploy the stack with Compose, env vars, persistence and backups
2. Design an n8n-based AI gateway (access, logging, policy, cost)
3. Call a FastAPI RAG service from n8n
4. Route between local and cloud models by policy
5. Explain scaling options (queue mode)
