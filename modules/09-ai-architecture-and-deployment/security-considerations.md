# Module 09 — Security Considerations

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

| Risk | Control |
|---|---|
| Gateway credentials leaked | Header auth via credentials; rotate; per-app keys |
| Misrouting sensitive data to cloud | Default-deny routing; classification tests |
| Backups contain sensitive data | Encrypt backups; restrict access; retention |

See also the [AI security playbook](../../docs/06-ai-security-playbook.md).
