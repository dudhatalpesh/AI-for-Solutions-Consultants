# Module 09 — AI Architecture and Deployment

**Phase 8 · Week 9 (standard) · ~4 hours · Intermediate–Advanced**

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

## Why this matters for SCs

Moving from demo to production is where deals stall. SCs must speak to deployment, persistence, backups, scaling, model routing and the AI gateway pattern with the same fluency they bring to network and security architecture.

## Business use cases

- Central AI gateway for all internal apps
- Hybrid routing: sensitive data to local models, general tasks to cloud
- RAG microservice consumed by multiple workflows
