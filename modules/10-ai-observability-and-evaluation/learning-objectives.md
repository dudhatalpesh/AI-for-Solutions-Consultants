# Module 10 — Learning Objectives

> **Status: outline.** Structure and key points are in place; full content is tracked in [docs/11-suggested-first-issues.md](../../docs/11-suggested-first-issues.md).

By the end of this module you can:

1. Define quality, cost, latency, reliability and safety metrics
2. Log LLM calls and errors to Postgres from n8n
3. Build an alerting workflow on thresholds
4. Create a golden dataset and run an eval workflow
5. Present metrics in a customer readout
