# Code of Conduct

This project adopts the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

## Our standards

- Be respectful, constructive and patient. Many contributors are learning.
- Critique content, not people.
- Never share real customer data, personal data, credentials or confidential employer material in issues, pull requests, workflows or examples.
- Do not use the red-team material in this repo against systems you are not authorised to test.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, doxxing, and sharing others' private information.

## Enforcement

Report concerns privately to the repository owner via GitHub. Maintainers may edit or remove contributions and block contributors who do not follow this code.
